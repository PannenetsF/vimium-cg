Privacy Policy for Vimum CG

Last updated: August 26, 2026

Data Collection

Vimum CG does not collect, store, transmit, or share any personal data, browsing history, or user information. All extension data (such as user preferences, custom key mappings, and exclusion rules) is stored locally in the browser's built-in storage and never leaves the user's device.

Data Storage

All user settings are stored using the browser's native chrome.storage / browser.storage API. This data remains on the user's device and can be cleared at any time by removing the extension or clearing browser data.

Network Requests

Vimum CG does not make any network requests to remote servers. The extension operates entirely locally within the browser.

Third-Party Services

Vimum CG does not integrate with or send data to any third-party analytics, advertising, or tracking services.

Permissions

The extension requests browser permissions (such as tabs, history, bookmarks, storage) solely to provide keyboard-driven navigation and tab management features. These permissions are used locally and are never used to transmit data externally.

Contact

If you have any questions about this privacy policy, please open an issue on the GitHub repository.
